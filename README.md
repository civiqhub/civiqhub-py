# civiqhub

Python package by [CiviqHub](https://civiqhub.com).

**Status: preview, not functional yet.** Version 0.0.1 only reserves the `civiqhub` name on PyPI; it contains nothing but `__version__`.

`civiqhub` will become the collective decision layer of actants, human or not.

## Install

```bash
pip install civiqhub
```
